# GitLabSeminar

Лабораторна робота з **Git** у межах дисципліни *«Університетські студії»*.

## Про проєкт

Консольний застосунок на **C# (.NET)**, створений у Visual Studio. Він виводить привітання та поточну дату.

## Що зроблено в лабораторній

- [x] Створено локальний репозиторій (`git init`)
- [x] Підключено віддалений репозиторій на GitHub
- [x] Зроблено коміти та відправлено їх на `origin`
- [x] Додано `.gitignore` для Visual Studio
- [x] Створено гілку `develop` та об'єднано її з `master`

## Як запустити

```bash
dotnet run --project GitLabSeminar
```
